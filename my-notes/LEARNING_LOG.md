## 2026-11-17 · 开始 + 一维 KF + NIS
- 环境：VS Code + `.venv`（Anaconda Python 3.12），修复 book_format.py 的 distutils 问题

- 一维卡尔曼滤波 5 个公式（体重例子）：预测 P 变大（+Q），更新 P 变小（×(1−K)）
- x = x̄ + K·y = (1−K)·x̄ + K·z，是加权平均；K = P̄/(P̄+R) = 预测不确定性的占比
- S = Var(y) = P̄ + R（预测误差和秤的误差独立，方差相加）；S 是衡量 y 大小的"尺子"
- NIS = y²/S，设定正确时均值≈1；>1 过度自信，<1 过度保守；不需要真实值
- 卡住的地方：字母容易混（自己的错误：更新时从 z 出发而不是从 x̄ 出发）
